# CheckPoint2App - ASP.NET Core MVC Student Directory

A full-stack Student Directory and Authentication management application built with **ASP.NET Core MVC** (.NET 10) and **Entity Framework Core (SQLite)**.

## 🚀 Tech Stack

* **Framework:** ASP.NET Core MVC (.NET 10)
* **ORM:** Entity Framework Core
* **Database:** SQLite (`app.db`)
* **Frontend:** Razor Views, Bootstrap, HTML5/CSS3

## 🛠️ Features

* **Student Directory Management:** Full CRUD operations (Create, Read, Update, Delete) for student records.
* **Database Seeding:** Automatically seeds 10 realistic sample student records on startup if the database is empty.
* **Account Authentication:** `AccountController` handles registration and user login against the SQLite database.
